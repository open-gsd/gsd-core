**plan-phase's stall watch now waits for the planner and plan-checker to actually return** — it no longer reports them finished at its first check because their own prompt or definition mentions the return markers, and a finished plan revision now continues instead of always ending in the stall menu. Each watched spawn writes a one-line return receipt under the phase's gitignored `.gsd-returns/`; the plan-checker writes its receipt through its shell and keeps its read-only tool set, so no host's tool grants change. No receipt is created for an unsafe phase directory: an empty path; one holding a quote, `$`, a backtick, `<`, `>` or a control character; a path with a `.` or `..` component; a symlink, dangling or not, at the phase directory or at any path component up to its nearest existing ancestor; one that resolves outside the project root plan-phase resolved (for example through a symlinked parent), or a project root or ancestor that does not resolve; the project root itself; anything inside `.git` below the project root, in any letter case and under the names Windows reads as `.git` (a trailing dot or space, `GIT~1`); or a `.gsd-returns` directory or its `.gitignore` that is a symlink, resolves elsewhere, is not a regular file, or cannot be created or written. A one-line stderr reason names the refusal, and the watch then ends on the agent's own completion result or as stalled. Where a sandbox refuses the checker's shell write (Codex `read-only`), the checker's watch ends the same way. (#5182)
