**plan-phase's stall watch now waits for the planner and plan-checker to actually return** — it no longer reports them finished at its first check because their own prompt or definition mentions the return markers, and a finished plan revision now continues instead of always ending in the stall menu. Each watched spawn writes a one-line return receipt under the phase's gitignored `.gsd-returns/`; the plan-checker writes its receipt through its shell and keeps its read-only tool set, so no host's tool grants change. No receipt is created when the phase directory is a symlink or resolves outside the project root plan-phase resolved (for example through a symlinked parent), when its path has a `.` or `..` component, or when it holds a control character; a one-line stderr reason names the refusal, and the watch then ends on the agent's own completion result or as stalled. Where a sandbox refuses the checker's shell write (Codex `read-only`), the checker's watch ends the same way. (#5182)
