**The Community Capability Registry now lists Standing Orders** — discover the independently maintained `The-Artificer-of-Ciphers-LLC/standing-orders` capability, which holds project-wide business rules in one ORDERS.yaml, gives the planner only the rules that apply to the phase, blocks planning on rule conflicts or edits to a rule's check files, requires GSD's fail-first prover to prove each applicable test rule after every execution wave, and records at ship which rules the phase was held to, with exact install and uninstall commands.
