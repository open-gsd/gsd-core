**PR templates no longer link to 404 pages** — the default, feature, enhancement and registry-entry templates use absolute URLs. A relative href resolves against `/pull/N` in a PR body. The Documentation Updates anchor now has its two hyphens. Two behaviour changes come with the fix. A PR template, `CONTRIBUTING.md` or `docs/registries/README.md` edit now runs the `test-inert` lane (`isLightweight`, scripts/ci-test-scope.cjs:41) instead of skipping CI. The ADR link gate (`extractLinks` in scripts/gen-adr-index.cjs) stops reading some forms as links. These forms are `[a](x y)`, `[a]()`, a destination with an ASCII control character, an escaped bracket and an escaped parenthesis. The gate also stops reading `[a](<x<y>)`, `[a](<x)`, `[a](<x>y)` and a parenthesis inside a title or an angle destination. A title that is doubled, unterminated or followed by other text ends the link too. The gate now reads block structure as CommonMark does (`scanBlocks`). A link in indented code, in an HTML block or comment, in a fence inside a quote or list item, in a reference definition, or in a code span that crosses a line is no link. A link whose text holds another link is no link. (#5427)
