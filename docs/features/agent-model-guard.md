title: Agent Model Guard

**Purpose:** Catch an orchestrator that dispatches a guarded GSD agent on a model other than the one GSD resolved for it (#5328).

PreToolUse hook. Besides the isolation-parameter check, on Claude Code it compares the `model` passed to `Agent()`/`Task()` for `gsd-executor`, `gsd-verifier`, `gsd-plan-checker` and `gsd-planner` with the resolved model (tier level: `claude-sonnet-4-6` equals `sonnet`). `hooks.agent_model_guard`: `"warn"` (default; any other stored value behaves as warn) adds model-visible context on mismatch, `"deny"` blocks a wrong or an omitted model, `false` disables. A deliberate escalation via `resolve-execution <agent>` (`--attempt N` or `--failure-class`) writes a single-slot `.gsd/model-escalation-<agent>.json` that the guard honours for 10 minutes, only for a model of the same tier family and, when both the dispatch and the record carry a session id, only if `resolve-execution` ran in that session; nothing clears it earlier. `--attempt N` records only when `dynamic_routing` `tier_models` or a quota `--failure-class` resolves a model other than the baseline; otherwise it resolves the baseline and records nothing, so under `"deny"` pass the resolved model. When `init` runs with `--ws`, it records that workstream name for the session (`recordInitWorkstream`; the hook reads it with `peekInitWorkstream`), only where the guard applies and the workstream's planning directory exists; the session keeps its newest eight workstreams, each for 12 hours and refreshed by naming it again with `init --ws`; a model matching any of them or the one `GSD_WORKSTREAM` or the session's pointer selects passes, the mismatch text names every such model, and a session whose record holds an entry older than 12 hours, or, where workstreams exist, a dispatch with no session id, is allowed, as the workstream `init` used cannot be established. Each `init` where the guard applies removes this project's carry files that hold no readable entry from the last 7 days (an empty, unreadable or oversized file included). Two plans in one wave that escalate the same agent type to different models overwrite each other's single-slot record, so under `"deny"` the first one's dispatch is blocked when the replacement model is in a different tier family (a same-family escalation passes). Fails open on any inability to verify, including a root `.planning/config.json` larger than 1 MiB, so `"deny"` is not enforced then.
